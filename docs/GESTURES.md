# 제스처 스펙

| 상황 | 동작 | 결과 |
|---|---|---|
| 영상 | 용두 / 위·아래 스와이프 | 다음·이전 영상 |
| 영상 | 화면 더블 탭 (손가락 더블 탭은 지원 기기만) | 좋아요 |
| 영상 | 오른쪽 → 왼쪽 스와이프 | 댓글창 열기 |
| 댓글창 | 오른쪽 → 왼쪽 스와이프 | 댓글창 닫기 (토글) |
| 댓글창 | 용두 / 위·아래 스와이프 | 댓글 목록 스크롤 (영상은 고정) |
| 댓글창 | 댓글 더블 탭 | 그 댓글에 하트 (화면 더블 탭만, 손가락 더블 탭 X) |
| 영상 | 전송 버튼 | DM방 선택 후 공유 |

## 결정 사항

- 댓글은 **읽기 전용**. 입력창, 받아쓰기, 손글씨 없음. 하트만 가능.
- DM은 **대화 기능 없음**. 공유할 방을 고르는 목록만 있음 (최근 순, 용두 스크롤, 탭으로 선택/해제, 하단 "보내기").
- 손목 돌리기 제스처는 제외 (공개 API 없음, 오작동 위험).
- 댓글창이 열려 있는 동안 영상은 일시정지 또는 음소거 (배터리).
- 닫기 방향이 열기와 같아서 공간 감각이 어긋나므로, 닫힐 때는 패널이 왼쪽으로 빠지는 애니메이션을 쓴다.

## 구현 메모

- 댓글 `ScrollView`에만 `digitalCrownRotation`을 붙이고, 댓글창이 열려 있을 때 영상 쪽 용두 핸들러는 끈다.
- 가로 스와이프는 가장자리 시작을 요구하지 않고, 가로 이동량이 세로보다 클 때만 인식한다.

## 구현 현황

- 구현됨: 용두/위·아래 스와이프 이동, 화면 더블 탭 좋아요(하트 애니메이션 + 햅틱), 왼쪽 스와이프 댓글 토글(오른쪽 스와이프로도 닫힘), 댓글 더블 탭 하트, DM방 다중 선택 공유.
- 미구현: 손가락 더블 탭(`handGestureShortcut`, watchOS 11+), 실제 영상 재생(`AVPlayer`), 댓글창이 열렸을 때 영상 일시정지(재생을 붙일 때 같이 처리).
- 스와이프 판정은 `SwipeIntent.classify`에 모여 있다 (최소 30pt, 주축이 반대축의 1.5배 이상).
